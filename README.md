# Ferretería Los Maestros

Tienda online para Ferretería Los Maestros, negocio familiar de La Serena. Proyecto semestral de la asignatura Desarrollo Fullstack II (DSY1104, Duoc UC).

## Estructura del repositorio

| Carpeta                  | Contenido                                                          | Estado          |
| ------------------------ | ------------------------------------------------------------------ | --------------- |
| [`frontend/`](frontend/) | SPA en React 19 + Vite + Tailwind CSS: catálogo, carrito y paneles | Funcional (EP2) |
| `backend/`               | API REST                                                           | Próximamente    |

Las instrucciones de instalación, los comandos y las cuentas de demostración están en el [README del frontend](frontend/README.md).

## Inicio rápido

```bash
cd frontend
npm install
npm run dev
```

Requiere Node.js `^20.19.0` o `>=22.12.0`.
